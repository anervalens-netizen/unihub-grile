# Whole-stack proof through Docker Compose web proxy

Every probe below was issued against the Vite dev server on :5173; the
Vite dev proxy (configured with UGRILE_API_PROXY=http://api:8080)
forwards each /api/* request to the FastAPI container. This proves the
S1 attempt-1 NO-GO on the Compose web-to-API routing is fixed.
